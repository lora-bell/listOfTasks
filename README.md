# 📋 Таблица управления заданиями

## 📖 Инструкция

На странице вверху добавлен **аккордеон** (раскрывающийся блок) с полной инструкцией по использованию. Заголовок **"Инструкция"** с иконкой `▽` / `△`, при клике открывается подробное описание функционала.

---

## 🎯 Функционал проекта

### ➕ Добавление записей (Create)

- При заполнении всех полей и нажатии кнопки **"Добавить"** - новая строка появляется в таблице
- Если поля не заполнены - показывается сообщение об ошибке: **"Чтобы добавить запись заполните все поля"**

### 📖 Просмотр и фильтрация записей (Read)

- Все добавленные записи отображаются в таблице
- Строки можно фильтровать по кнопке:
  - **"Показать невыполненные задания"** — скрываются записи с выполненными ДЗ, текст кнопки меняется на **"Показать все задания"**
  - **"Показать все задания"** — все скрытые записи возвращаются, текст кнопки меняется обратно

### ✏️ Редактирование записей (Update)

- Ячейка **"Статус"** содержит текст (выполнено/не выполнено) и иконку карандаша ✏️
- При клике на ячейку статус переключается: `выполнено` ↔ `не выполнено`

### 🗑️ Удаление записей (Delete)

- **Двойной клик** по строке — запись удаляется из таблицы

### 🎨 Визуальные эффекты при взаимодействии со строками

| Действие | Результат |
|----------|-----------|
| **Наведение** на строку | Вся строка меняет фон на светло-серый |
| **Клик** по строке | Строка меняет фон на тёмно-серый |

### 📱 Адаптивная вёрстка

При необходимости таблица получает горизонтальную полосу прокрутки.
