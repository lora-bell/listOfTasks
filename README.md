# 📋 Таблица управления заданиями

## 🎯 Функционал проекта

### ➕ Добавление записей

- При заполнении всех полей и нажатии кнопки **"Добавить"** - новая строка появляется в таблице
- Если поля не заполнены - показывается сообщение об ошибке: **"Чтобы добавить запись заполните все поля"**

### 🎨 Взаимодействие со строками

| Действие | Результат |
|----------|-----------|
| **Наведение** на строку | Вся строка меняет фон на `#D3D3D3` |
| **Клик** по строке | Строка меняет фон на `#A9A9A9` |
| **Двойной клик** по строке | Запись удаляется из таблицы |

### 🔍 Фильтрация

Строки в таблице можно фильтровать по кнопке **"Показать невыполненные/все задания"**

#### Режимы работы кнопки:

| Текст на кнопке | Действие кнопки |
|-----------------|-----------------|
| **"Показать невыполненные задания"** | Из таблицы отфильтровываются записи с выполненными ДЗ |
| **"Показать все задания"** | Все отфильтрованные элементы возвращаются в таблицу |
